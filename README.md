# Full Cycle

Site da Full Cycle, consultoria ambiental da bióloga Gabriela Gomes em Santa Catarina.

Feito com Next.js e Tailwind CSS.

## Rodando local

```bash
npm install
npm run dev
```

Abre em http://localhost:3000.

## Onde mexer

- Textos, serviços, FAQ e contatos: `src/lib/constants.ts`
- Cores e fontes: `src/app/globals.css`
- Seções da página: `src/components/`

A URL do site pode ser trocada com a variável `NEXT_PUBLIC_SITE_URL`.
